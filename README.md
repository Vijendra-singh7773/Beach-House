# Beach House — Restaurant Website

A responsive, animated one-page restaurant demo for Beach House, Djibouti.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Customize
- Replace photos in `assets/` with approved restaurant images.
- Update menu descriptions, opening hours, and contact details in `index.html`.
- Update styles in `style.css`.

## Included
- Responsive navigation and mobile menu
- Scroll reveal animations and subtle hero zoom
- Menu highlights, photo gallery, location/contact section
- Phone and Google Maps links
- Reduced-motion accessibility support

This is a static front-end demo; it does not include online ordering or a reservation backend.
